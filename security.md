# Security Policy

## Supported Versions

| Version | Supported |
|----------|-----------|
| 1.x.x | ✅ |
| <1.0 | ❌ |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public GitHub issue.

Instead:

- Describe the vulnerability.
- Include reproduction steps.
- Explain the potential impact.
- Provide logs or screenshots if possible.

The report will be reviewed as quickly as possible.

---

## Security Goals

This project aims to:

- Protect user configuration.
- Never collect personal information.
- Never send telemetry.
- Never upload data without user consent.
- Keep authentication tokens stored securely using the operating system keyring whenever possible.

---

## Disclosure Policy

Security issues will be fixed before public disclosure whenever possible.

Thank you for helping improve the security of this project.
